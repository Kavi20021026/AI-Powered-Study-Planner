# AI-Powered-Study-Planner
AI-powered study planner web application that generates personalized study schedules based on subject priority and exam deadlines. Built with PHP, MySQL, HTML, CSS, and JavaScript.

## 📖 Overview

The AI Study Planner assists students in planning their daily study sessions by analyzing factors such as subject difficulty, exam dates, and study priorities. The system provides an intuitive dashboard for managing subjects, tracking progress, and staying organized throughout the semester.

---

## ✨ Features

- 🔐 Secure User Authentication
- 📚 Subject Management (Create, Update, Delete)
- 🤖 AI-Based Study Plan Generation
- 📅 Interactive Calendar View
- 📈 Study Progress Tracking
- 🔔 Browser Notification Reminders
- 📄 Export Study Plans as PDF
- 🌙 Dark Mode
- 📱 Fully Responsive User Interface

## 🚀 Installation

### Prerequisites

- PHP 8+
- MySQL
- XAMPP

### Steps

1. Clone the repository

```bash
git clone https://github.com/yourusername/AI-Study-Planner.git
```

2. Move the project into the XAMPP `htdocs` directory.

3. Start Apache and MySQL.

4. Create a new MySQL database.

5. Import the SQL file located in the `database` folder.

6. Update your database configuration if required.

7. Open your browser and navigate to:

```
http://localhost/AI-Study-Planner
```

## 🧠 AI Study Plan Logic

The study planner generates schedules using a priority-based algorithm that considers:

- Subject difficulty
- Exam deadlines
- Study priority
- Remaining preparation time

This helps students focus on high-priority subjects while maintaining a balanced study schedule.
